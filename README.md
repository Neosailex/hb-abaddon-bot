# HB Abaddon Bot

Bot "idle" para Helbreath Abaddon (guerrero, Aresden). Lee la memoria del juego en modo solo lectura para saber dónde está y qué hay alrededor, y juega con clicks y teclas como una persona. No escribe memoria ni manda paquetes.

## Instalar

1. Bajá este repo (Code → Download ZIP) y descomprimilo.
2. `instalar.bat` (instala Python y las librerías la primera vez).
3. `iniciar.bat` para abrirlo. Si el juego no responde a los clicks, `iniciar_admin.bat`.

## Auto-actualización

`iniciar.bat` busca una versión nueva en este repo antes de abrir, y el bot vuelve a mirar cada 20 minutos mientras está abierto. Nunca pisa lo tuyo: configuración, contraseña (cifrada, solo en tu PC), lo aprendido, registros ni plantillas.

## Qué hace

- Caza, levanta, come, toma pociones, reparte stats, repara el equipo y compra provisiones.
- Mapa del mundo con el arte del propio juego (botón "Mapa"), rutas entre mapas y plan por nivel.
- Botón "Investigar": recorre tiendas y bolso y deja fotos para seguir programando.

Uso bajo tu responsabilidad y solo donde el servidor lo permita.
