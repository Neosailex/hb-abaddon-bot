# Reglas del proyecto

## Regla absoluta
Todo arreglo es para el bot, no para un personaje.
- Tiene que servir para cualquier pj, de nivel 1 a 200, en el server (después, por juego).
- Si un arreglo solo sirve para el pj actual, no está terminado: se mejora hasta que sea regla general.
- Nada de corregir el estado de un pj a mano por consola como solución: la consola es para diagnosticar.
  Si hubo que tocar la config de un pj, ese caso se convierte en regla en el código.
- Los umbrales (pasar a dos manos, cambiar de mapa, etc.) se activan una vez y quedan fijos para siempre.
  Antes de llegar al umbral, no se aplican.
